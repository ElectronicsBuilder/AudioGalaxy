# AudioGalaxy

Audio player firmware for the STM32F407G-DISC1 Discovery board. It plays WAV
files from a USB stick through the on-board CS43L22 codec and records from
the on-board microphone. It is controlled over a serial link by
[BeaconGalaxy](https://github.com/ElectronicsBuilder/BeaconGalaxy).

Part of a three-repository system: [BeaconGalaxy](https://github.com/ElectronicsBuilder/BeaconGalaxy)
(the matrix and menu controller), [GalaxyBoot](https://github.com/ElectronicsBuilder/GalaxyBoot)
(its bootloader) and **AudioGalaxy** (this one).

## Features

- **Playback:** WAV files from the USB stick root, up to 100 tracks.
  - RIFF files are parsed properly: 8- or 16-bit, mono or stereo, at the
    file's own sample rate.
  - Play, stop, pause/resume, next/previous, volume and repeat.
  - Pause keeps the codec powered and plays silence, and stop powers it down
    cleanly, so the speaker doesn't hiss.
- **Recording:** `rec.wav`, up to 30 s, from the MP45DT02 microphone.
- **Link to BeaconGalaxy:** USART2 on PA2/PA3, 115200 baud, ASCII
  `GALAXY...` commands and events. See [docs/protocol.md](docs/protocol.md).
- **Board controls:** the blue LED is lit while playing and the red LED while
  recording. The user button starts, pauses and resumes playback.

## Build

You need STM32CubeCLT 1.16 (arm-none-eabi-gcc, CMake, Ninja) on the PATH.

```
cmake --preset Debug
cmake --build --preset Debug
```

## Flash

```
STM32_Programmer_CLI -c port=SWD sn=<st-link serial> mode=UR -w build/Debug/AudioGalaxy.elf -v -rst
```

VS Code tasks (`.vscode/tasks.json`) cover building, flashing, the console
over SWD, the host tests and the CI checks.

## Console

- **Serial:** USART3, PD8 (TX) / PD9 (RX), 115200 baud.
- **Over SWD, no wiring:**
  `python tools/swd_console.py build/Debug/AudioGalaxy.elf <st-link serial> "help"`

Commands include `status`, `ls`, `play`, `pause`, `resume`, `stop`, `vol`,
`repeat`, `rec start|stop` and `link`. `gx <GALAXY...>` handles a link
command as if BeaconGalaxy had sent it.

## Layout

| Folder | Contents |
|---|---|
| `App/` | our code: player task (`Player/`: WAV parser, playlist, playback, recording), link, console, board support (`Bsp/`: ST's Discovery audio drivers and PDM library) |
| `common/` | code shared with BeaconGalaxy and GalaxyBoot (console, CRC, protocol, UART streams) |
| `Core/`, `Drivers/`, `Middlewares/`, `FATFS/`, `USB_HOST/` | generated by STM32CubeMX 6.15. Edit `AudioGalaxy.ioc` (changes are recorded in `cubemx/audiogalaxy.patch`), then run `sh tools/cubemx_generate.sh .` |
| `tests/host/` | PC unit tests: `sh tests/host/run_tests.sh` |
| `docs/` | [protocol](docs/protocol.md) and the [system overview](docs/port-writeup.md) |
